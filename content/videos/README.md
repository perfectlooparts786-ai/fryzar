# Content Videos Queue (Free Auto-Uploader)

Apni sari 3D / satisfying loop videos (.mp4) is folder mein daal dein:
`content/videos/`

### File Naming Convention:
Video ka naam simple aur descriptive rakhein, script automatically is se viral title bana legi:
- `marble_chain_reaction.mp4`
- `liquid_gold_ring.mp4`
- `infinite_gear_satisfaction.mp4`

Jab GitHub Actions chalega:
1. Is folder se pehli video uthaye ga.
2. Uska viral packaging aur pinned comment banaye ga.
3. YouTube par upload karega.
4. Upload hone ke baad video ko `content/published/` folder mein shift kar dega taake repeat na ho!
